# FitTracker

App móvil de seguimiento de entrenamientos, hecha con React Native + Expo.
Proyecto integrador del curso Desarrollo de Aplicaciones Móviles con React Native (CIT FPUNA–KOICA).

## Funcionalidades (Hito Semana 3)
- Formulario controlado (`TextInput` + `useState`): ejercicio, series, repeticiones y peso.
- Validación de campos con mensaje de error en pantalla.
- Alta y baja de ejercicios en una lista de estado.
- `useEffect` para registrar los cambios de la lista.

## Cómo ejecutarla
```bash
npm install
npx expo start
```
Presioná `a` para abrir el emulador Android, o escaneá el QR con Expo Go.
